# 聚玩数据中台前端

面向前端维护与质量改进的独立代码仓库。

| 目录 | 内容 | 修改方式 |
| --- | --- | --- |
| `system-console/src` | React 18、Ant Design 5 系统管理源码 | 修改源码并构建 |
| `system-console/public` | 登录图片、参数配置独立页面 | 修改对应资源 |
| `web` | 主站编译资源、独立页面及补充脚本 | 有源码的脚本直接修改；主站 React 完整源码不在本仓库 |
| `scripts` | 本机静态预览服务 | Node.js 原生模块 |
| `docs` | 接口边界、交接与验证说明 | 按实际实现维护 |

## 启动

使用 Node.js 22 或更高版本及 npm：

```sh
npm run setup
npm run build
npm run preview
```

打开 http://127.0.0.1:8401/ 浏览主站，http://127.0.0.1:8401/admin 浏览源码构建的系统管理入口。未登录的系统管理入口进入登录页；主站可显示页面结构、空数据状态或嵌入的示例内容，登录与业务查询需要接口。

系统管理源码热更新：

```sh
npm run dev
```

打开 http://127.0.0.1:8399/admin 。独立主站页面使用 `web` 中的对应 HTML 入口。开发服务与预览服务默认仅监听本机。

## 测试后端

通过进程环境变量 `DC_API_TARGET` 指定已授权的测试后端地址，再启动开发或预览服务。仅 `/api/` 请求会代理。不要设置生产后端；包含新增、编辑、删除的页面操作会实际调用指定后端。

未配置后端时，预览服务返回 JSON 503，不提供模拟登录或伪造业务统计。凭据不随代码交付，也不要在 Claude 对话中提交账号、密码或令牌。

## 代码与数据边界

公开代码快照取自 2026-10-12 本地工作区，包含尚未发布的本地前端改动，不代表同日生产版本。仓库使用独立 Git 历史。

不包含服务端、采集程序、数据库、配置账号清单、运行状态文件、备份和原项目历史。静态资源里的示例身份已匿名化，示例内网 IP 使用文档示例地址；内部服务跳转使用 `example.invalid` 占位域名。脚本内的示例金额、图表和聊天内容只能用于界面预览，不能用于业务验收。

主站原始 React 工程缺失；不要把编译包格式化后称为恢复的源码。完整组件重构需要另行取得原始工程。
