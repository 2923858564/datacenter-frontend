## 重建边界

主站基于公共前端快照 `d95aace` 重建。原始变量名、注释与 JSX 写法无法全部恢复，现有源码保留部分短变量名与 JSX 运行时调用。模块引用中的缓存参数统一后，同一模块只实例化一次；复用加载占位使用正确的空节点工厂，避免错误调用表格组件。

`web` 是历史静态对照快照，其中复用文件的旧问题仍保留；默认预览从 `main-app/dist` 加载当前构建。历史主站原型与渠道原始源码来自不同版本，只供源码对照和独立审查，不覆盖当前路由。

独立传统脚本通过构建插件按原始路径输出，保留其加载顺序与全局接口；Vite 对这些非模块脚本的提示不代表它们被遗漏。构建仍提示部分模块较大，体积优化留待另行确认。

## 管理端失败处理与交互

花名册保留停用筛选的数值 0，删除后自动回到有效页码；每行账号状态请求串行执行，服务端确认的状态立即显示。资料保存与角色保存的部分成功分别提示，角色失败时刷新列表并保留表单。

请求层把超时、断网、异常成功响应转换为明确错误；花名册和身份响应检查必要结构。登录 401 保留账号或密码错误，受保护请求 401 清除对应会话，过期旧请求不能清除新会话。GET 无请求体时不发送 JSON Content-Type。用户列表防缓存时间戳保留。

管理端状态层统一验证身份，失败时阻止管理页操作并提供重试；共享鉴权脚本接收有效身份更新导航，不另发身份请求或缓存异常身份响应。状态开关与操作按钮包含员工姓名标签，复制失败显示手动复制提示。
