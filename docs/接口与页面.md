# 接口与页面

主站当前逻辑位于 `main-app/src/runtime/application.js`、`src/pages`、`src/extensions` 与 `src/modules`；接口地址和字段以实际请求代码为准。管理端 API 封装位于 `system-console/src/api.js`，状态位于 `store.jsx`，共享鉴权脚本位于 `system-console/public/__auth_gate__.js`。

| 页面 | 路由或入口 | 源码 |
| --- | --- | --- |
| 主站首页 | `/` | `main-app/src/pages/DashboardPage.js` |
| 数据集 | `/integration` 及各子路由 | `main-app/src/pages/DataDetailPage.js` |
| 私域与人员排行 | `/dashboard/private-domain`、`/dashboard/performance-ranking` | `PrivateDomainPage.js`、`PerformanceRankingPage.js` |
| 联系人、工单 | `/contacts.html`、`/work-orders.html` | `main-app/src/extensions/contacts.js`、`work-orders.js` |
| 复用看板 | `/reuse-standalone.html` | `main-app/src/modules/reuse-CiOE-ogp.js` |
| 登录 | `/login` | 管理端 `LoginPage.jsx`；主站内部入口 `MainLoginPage.js` |
| 花名册 | `/admin` | `system-console/src/pages/SystemUsers.jsx` |
| 项目册 | `/admin/config` | `system-console/src/pages/PackageConfig.jsx` |
| 部门管理 | `/admin/departments` | `system-console/src/pages/PersonnelArchive.jsx` |
| 数据字典 | `/admin/dictionary` | `system-console/src/pages/SystemDictionary.jsx` |
| 操作日志 | `/admin/audit` | `system-console/src/pages/SystemAudit.jsx` |

管理端通过 sessionStorage 的 `dc_token` 和 `Authorization: Bearer` 发送会话令牌；服务端负责身份及权限，前端菜单不能作为授权依据。主站的历史兼容鉴权代码保留在运行模块和共享脚本中，调整前需核对服务端协议。

仓库没有后端实现。无后端时只能验收页面结构、资源、构建、缺失状态和错误处理，不能完成真实登录、业务查询或写入验收。

管理端身份请求由状态层统一发起；只有验证成功才渲染管理页面并通知共享脚本更新导航。非 401 失败保留会话并提供重试，401 清除对应会话。
