# 接口与页面

所有业务数据依赖 `/api/v1/*`。系统管理 API 封装在 `system-console/src/api.js`，鉴权状态在 `system-console/src/store.jsx`；主站共享鉴权脚本为 `web/__auth_gate__.js`。

会话令牌从 sessionStorage 的 `dc_token` 读取，通过 `Authorization: Bearer` 请求头发送。服务端负责身份和权限；前端菜单不可作为授权依据。

| 页面 | 路由或入口 | 主要接口 |
| --- | --- | --- |
| 登录 | `/login` | `/api/v1/auth/*` |
| 花名册 | `/admin` | `/api/v1/system/users` |
| 项目册 | `/admin/config` | `/api/v1/system/package-config/*` |
| 部门管理 | `/admin/departments` | `/api/v1/personnel/archive` |
| 数据字典 | `/admin/dictionary` | 字典、游戏区服、工单分级接口 |
| 操作日志 | `/admin/audit` | `/api/v1/system/audit-logs` |
| 主站看板与数据集 | `/`、`/integration` 等 | 以 `web` 中对应请求代码为准 |
| 联系人、工单 | `/contacts.html`、`/work-orders.html` | 以对应独立脚本为准 |

字段与方法以代码中的实际请求为准。仓库没有后端实现；不承诺独立前端能够完成真实登录、查询、编辑或导出业务数据。

`system-console` 的 Vite 配置支持 `/admin` 子路由和 `/login` 页面入口。`web` 的主站脚本与系统管理源码各自独立，主站入口不能通过本仓库重新编译。
